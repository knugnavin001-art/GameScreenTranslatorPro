# Screen Translate Clean

ต้นแบบแอปแปลข้อความบนหน้าจอเป็นภาษาไทย โดยเน้น UI เรียบง่ายและไม่มีโฆษณา/ระบบชำระเงิน

## สิ่งที่มีในโปรเจกต์
- ปุ่มลอยสำหรับเริ่มแปลหน้าจอ
- จับภาพหน้าจอผ่าน Android Accessibility Service เมื่อผู้ใช้แตะปุ่ม
- OCR ผ่าน Google ML Kit (รุ่นปัจจุบันรองรับอักษรละตินเป็นหลัก)
- แปลเป็นภาษาไทยผ่าน MyMemory API โดยต้องเชื่อมต่ออินเทอร์เน็ต
- หน้าตั้งค่าที่จัดใหม่ให้สะอาดและอ่านง่าย

## ไม่มี
- ไม่มี Billing permission หรือ SDK สำหรับซื้อภายในแอป
- ไม่มี AD_ID permission หรือ SDK โฆษณา
- ไม่มีหน้าสมัครสมาชิกหรือระบบจ่ายเงิน

## สร้าง APK
GitHub Actions workflow อยู่ที่ `.github/workflows/build-apk.yml` สร้าง Debug APK และแนบ Artifact ชื่อ `ScreenTranslateClean-debug-apk`

## ข้อจำกัด
- นี่คือโปรเจกต์ต้นแบบใหม่ ไม่ใช่การแก้ไขหรือแจกจ่าย APK ต้นฉบับ Bubble Screen Translate
- ยังไม่ได้ยืนยันว่าบิลด์ผ่านจนกว่าจะรัน workflow จริง
- OCR สำหรับภาษาญี่ปุ่น จีน และเกาหลีต้องเพิ่มโมเดลที่เหมาะสม
- บริการแปลภายนอกอาจมีข้อจำกัดอัตราการใช้งาน
